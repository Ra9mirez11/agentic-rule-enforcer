> A lightweight pre-commit and CI gatekeeper that validates code generated by AI coding agents against local project rules, preventing secrets leakage, style drift, and rule violations before commits are finalized.

---

## 🎯 The Problem

Developers increasingly work with autonomous AI coding agents (Claude Code, Cursor, Antigravity, Aider). However, AI assistants commonly suffer from:
1. **Hardcoded Secrets**: Pasting API keys, private keys, or passwords directly into source code.
2. **Debug Noise & Fluff**: Leaving `print("TODO_DEBUG...")` or verbose console dumps in committed code.
3. **Rule Drift**: Ignoring project-specific conventions and architectural boundaries documented in markdown files.

Standard linters only check language syntax; they do not enforce conversational or team-specific guidelines established for AI agents.

## 💡 The Solution

**Agentic Rule Enforcer** bridges this gap:
- Reads human-readable guidelines directly from `agent_rules.md`.
- Compiles rules into deterministic inspection patterns.
- Reports exact 1-indexed line violations with surrounding context in a high-contrast terminal UI.
- Generates interactive, color-coded unified diffs for automated remediation (`fix`).
- Creates safety snapshots in `.agentic-enforcer/backups/` before modifying files, with instant single-command `rollback`.
- **Zero external dependencies**: Built with pure Python standard library for instant portability across Windows, macOS, and Linux.

## 🚀 Quickstart

### 1. Initialize Default Rulebook
Bootstrap a customizable `agent_rules.md` file in your repository:
```bash
python -m enforcer.cli init
```

### 2. Inspect Active Rules
Verify and inspect all compiled rules:
```bash
python -m enforcer.cli rules
```

### 3. Scan Codebase
Scan files for violations (returns exit code `0` if clean, `1` if violations are found):
```bash
python -m enforcer.cli scan [optional-target-path]
```

### 4. Interactively Remediate Violations
Preview the unified diff and safely apply automated fixes:
```bash
# Preview diff without modifying files
python -m enforcer.cli fix --dry-run

# Interactive review and patch application
python -m enforcer.cli fix
```

### 5. Instant Rollback
Revert remediated files back to their previous state:
```bash
python -m enforcer.cli rollback
```

## 🛠️ Customizing Rules (`agent_rules.md`)

Any developer can customize or add project-specific rules directly in Markdown without modifying Python code:

```markdown
### RULE-CUSTOM-01: Disallow Plain HTTP Endpoints
- Severity: HIGH
- Description: Enforce HTTPS for all external API endpoints.
- FileTypes: .py, .ts, .js, .json
- Pattern: `http://[a-zA-Z0-9.-]+`
- Fix: manual
- Message: Insecure HTTP endpoint detected; upgrade to HTTPS.
```

The enforcer automatically parses new `### RULE-...` sections and activates them on the next scan.
