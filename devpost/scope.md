# Agentic Rule Enforcer

A lightweight pre-commit and CI gatekeeper that validates code generated by AI coding agents against local project rules, preventing secrets leakage, style drift, and rule violations before commits are made.

## The Unique Kernel
Most linting tools only check syntax and language idioms; Agentic Rule Enforcer translates unstructured plain-text project guidelines (like `agent_rules.md` or `.rules`) into enforceable pre-commit guardrails and automatically drafts compliant diff fixes for violations caused by AI agents.

## Who It's For
Developers and security auditors working alongside autonomous AI coding agents (such as Claude Code, Cursor, Antigravity) who need automated guarantees that the agent won't violate local engineering policies, commit secrets, or bypass project standards.

## The Core Loop
1. The developer or pre-commit hook runs `agentic-rule-enforcer scan [target-path-or-diff]`.
2. The tool parses the project's rule file (e.g., `agent_rules.md`) and analyzes modified files or diffs.
3. The CLI renders a clear terminal summary table: PASS/FAIL per rule with exact file names, line numbers, and violation details.
4. If violations exist, the user can run `agentic-rule-enforcer fix` to review and apply an auto-generated compliant patch.

## Inspiration & Identity
- Inspired by modern developer CLI tools like `biome`, `ruff`, and `pre-commit`, but tailored specifically to conversational and project rulebooks used by AI coding agents.
- Interface style: Clean, high-contrast, informative terminal UI with unambiguous exit codes (0 for pass, 1 for fail) suitable for CI/CD and pre-commit hooks.

## Why This Matters to the Learner
Solves the recurring frustration where AI coding agents repeat known mistakes, hallucinate out-of-scope modifications, or leave hardcoded secrets in the codebase, while delivering a focused, reliable PoC for the Devpost hackathon.

## What "Working" Looks Like
In a 2-minute video:
1. Running the CLI against a codebase containing deliberate rule violations (e.g. hardcoded API secret, forbidden terminal log statement, unhandled error).
2. The tool immediately flags each violation with file path, line number, and rule reference, exiting with code 1.
3. Running the fix command produces the remediated code.
4. Re-running the scan displays all checks green (exit code 0).

## The POC Boundary
- CLI interface (Python or Node.js) with commands `scan` and `fix`.
- Rule engine capable of parsing local Markdown rule definitions (e.g. `agent_rules.md`).
- Deterministic checks for key high-risk patterns:
  - Secrets and credentials detector (API keys, private keys, tokens).
  - Terminal log / fluff pollution in output or code.
  - Scope guard (detecting modifications to protected or sensitive files).
- Auto-remediation generator providing standard unified diff output.

## Later
- Remote LLM-powered deep semantic rule evaluation for complex architectural rules.
- GitHub Actions CI workflow integration and bot PR commenting.
- Interactive terminal dashboard with TUI (Text User Interface).

## Explicitly Cut
- Complex multi-repo distributed monitoring (unnecessary for standalone PoC).
- Proprietary cloud backend or SaaS subscription features.
- Full IDE extension plugins (CLI provides broader universality for PoC demo).
